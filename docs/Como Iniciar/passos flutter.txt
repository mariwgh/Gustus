O arquivo principal fica em lib/main.dart.


import 'package:flutter/material.dart';

void main() {
  runApp(MeuApp());
}

class MeuApp extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      home: Scaffold(
        appBar: AppBar(title: Text("Meu Primeiro App")),
        body: Center(
          child: Text("Olá, Flutter!"),
        ),
      ),
    );
  }
}


Conceitos importantes

Widgets → tudo na tela é um widget (texto, botão, layout).

StatelessWidget → não muda (ex: texto fixo).

StatefulWidget → pode mudar (ex: contador, input).

Hot Reload → você salva e o app atualiza na hora.
