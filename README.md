## 🧠 Visão Geral

**Gustus** é uma ferramenta full-stack que permite criar uma plataforma culinária dinâmica com suporte multiplataforma.  
Construído com **Flutter**, **Node.js** e **PostgreSQL**, oferece uma arquitetura escalável para gerenciar perfis de usuários, receitas, favoritos, avaliações e listas de desejos.

### Por que o Gustus?

Este projeto facilita o desenvolvimento de aplicativos gastronômicos envolventes. Os principais recursos incluem:

- 🧩 **Arquitetura Modular:** Compatível com Web, iOS, Android, Windows, macOS e Linux.  
- 🚀 **Gerenciamento Escalável de Dados:** Lida eficientemente com interações e dados personalizados.  
- 🎯 **Configuração Amigável:** Estrutura de projeto clara e fácil de entender.  
- 🔒 **Back-end Seguro:** Implementa autenticação JWT e endpoints estruturados.  
- 🎨 **Experiência de Usuário Rica:** Permite navegar, favoritar e avaliar experiências gastronômicas com facilidade.

### 💿 Instalação

Construa o **Gustus** a partir do código-fonte e instale as dependências:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/mariwgh/Gustus
   ```

2. **Entre no diretório do projeto:**
   ```bash
   cd Gustus
   ```

3. **Verfifique os arquivos em docs (Como Iniciar) para maiores informações**

### 🧪 Testes

**Gustus** usa o framework de testes `{test_framework}`.  
Execute a suíte de testes com:

**Usando [pub](https://dart.dev/):**
```bash
pub run test
```

**Usando [cmake](https://isocpp.org/):**
```bash
ctest
```

**Usando [gradle](https://gradle.org/):**
```bash
gradle test
```

**Usando [npm](https://www.npmjs.com/):**
```bash
npm test
```
